# order_app
# پروژه مدیریت کارشناسان، مشتریان و ثبت سفارش

این پروژه یک اپلیکیشن وب مبتنی بر React است که برای مدیریت کارشناسان فروش، احراز هویت، مدیریت مشتریان، نمایش محصولات، و ثبت سفارش طراحی شده است.  
در بک‌اند نیز یک API مبتنی بر PHP/ERP برای دریافت لیست کارشناسان و مشتریان استفاده می‌شود.

---

## وضعیت فعلی پروژه

### بخش‌های پیاده‌سازی‌شده

- احراز هویت کارشناسان با شماره موبایل و رمز
- ذخیره وضعیت ورود در `localStorage`
- پشتیبانی از ورود مهمان
- مدیریت نقش‌های کاربر بر اساس داده‌های کارشناس
- نمایش محصولات و فیلتر بر اساس دسته‌بندی
- مدیریت مشتریان
- سبد خرید و محاسبات مجموع
- مودال ورود و مودال ثبت مشتری
- نمایش پیام خوش‌آمدگویی پس از ورود

### مشکلات/ریسک‌های فعلی

- پاسخ بک‌اند در برخی مسیرها JSON معتبر نیست و باعث خطای parse در فرانت می‌شود.
- منطق لاگین فعلی مستقیماً کارشناسان را بر اساس `mobile + password` تطبیق می‌دهد.
- برخی متغیرها و توابع در `App.jsx` هنوز به‌صورت ناقص یا تعریف‌نشده استفاده شده‌اند.
- ساختار احراز هویت کارشناسان هنوز به تفکیک کامل `register` / `login` / `forgot password` تبدیل نشده است.

## جریان احراز هویت کارشناسان

### 1) ورود اولیه

کاربر شماره موبایل و رمز را وارد می‌کند.  
سپس لیست کارشناسان از API دریافت می‌شود:

- `GET /api/Expert/sync`
- `GET /api/Expert`

### 2) تطبیق کارشناس

در حال حاضر تطبیق بر اساس این فیلدها انجام می‌شود:

- `mobile`
- `password` یا fallback روی `code`

### 3) ذخیره وضعیت ورود

پس از موفقیت، اطلاعات کاربر در `localStorage` ذخیره می‌شود:

- کلید: `TOT_AUTH_EXPERTS`
- مدت اعتبار: ۷ روز

### 4) ورود مهمان

کاربر می‌تواند بدون لاگین کامل، به‌صورت مهمان وارد شود.

## منطق فعلی `useAuthExpert`

این هوک وظایف زیر را انجام می‌دهد:

- باز و بسته کردن مودال احراز هویت
- نگهداری stateهای ورود
- دریافت لیست کارشناسان
- بررسی کاربر ذخیره‌شده در localStorage
- ورود مهمان
- خروج کاربر

## مشکلات فنی شناخته‌شده

- بک‌اند در برخی درخواست‌ها خروجی غیر JSON می‌دهد.
- در `App.jsx` چند متغیر مثل `isSubmitting`، `orderDescription`، `currentUser`، `submitOrder` هنوز تعریف نشده‌اند.
- در بخش دریافت مشتریان، یک fallback ناقص وجود دارد.
- ایمپورت‌ها و نام‌گذاری‌ها نیاز به تمیزکاری دارند.
